## 📄 .gitignore (Versión Definitiva)

Este archivo le dice a Git qué **NO** subir a GitHub. Es esencial para mantener tu repositorio limpio y evitar subir archivos pesados o innecesarios.

```gitignore
# Entornos virtuales
venv/
env/
.venv/

# Archivos de Python
__pycache__/
*.pyc
*.pyo
*.pyd
.Python

# Archivos de datos grandes (se regeneran con el código)
*.pkl
*.csv
*.log

# Modelos guardados (opcional, si quieres subir el pipeline, puedes comentar esta línea)
# *.pkl

# Configuraciones de editores
.vscode/
.idea/
*.swp
*.swo

# Archivos de sistema
.DS_Store
Thumbs.db

# Archivos de Power BI (si son muy grandes)
*.pbix
*.pbip
!dashboard/

# Archivos de entorno
.env
.env.local

# Archivos de cobertura de pruebas
.coverage
htmlcov/
